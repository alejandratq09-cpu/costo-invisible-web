Una experiencia para pensar

El costo invisible de llegar al final del día

Un día cualquiera está hecho de decisiones que parecen pequeñas: cómo salir de casa, qué comer, cómo moverse, qué hacer con el cansancio. Cada una cuesta dinero, pero también tiempo, energía y bienestar.

Vas a recorrer seis momentos de un día. En cada uno elegirás entre dos o tres opciones y verás cómo cambian cuatro indicadores. No hay respuestas correctas, no hay puntaje y nadie gana ni pierde: al final recibirás un recibo invisible con todo lo que costó llegar hasta ahí.

Elige el día que quieres recorrer

La experiencia es anónima: no pedimos nombre, correo ni ningún dato personal. Solo se guardan las opciones elegidas, sin identificarte, para mostrar estadísticas agregadas.

              Qué revisar

              1. Que PostgreSQL esté encendido y acepte conexiones.
              2. Que el archivo .env exista y tenga una DATABASE_URL correcta.
              3. Que hayas ejecutado npm run db:init para crear las tablas.
              4. Después, reinicia el servidor con npm start y pulsa «Reintentar».
